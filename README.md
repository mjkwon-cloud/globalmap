# 🌍 글로벌 채널맵 (Global Channel Map)

K-Beauty 글로벌 채널 분석 및 관리 시스템

## 📋 개요

**글로벌 채널맵**은 K-Beauty 브랜드의 국가별 입점 현황, 유통사 정보, 취급 브랜드를 한눈에 볼 수 있는 인터랙티브 데이터 분석 플랫폼입니다.

### 주요 기능

- 🗺️ **Google Maps 통합**: 25개 국가별 입점 현황 시각화
- 🔍 **고급 필터링**: 국가, 브랜드, 채널 기준 검색 (AND 조건)
- 📊 **실시간 통계**: 채널, 국가, 브랜드, 거래처 KPI 자동 계산
- 📁 **CSV 업로드**: 언제든 새로운 데이터 로드 가능
- 🎯 **상세 정보**: 국가별 채널별 상세 정보 패널

## ⚙️ Google Maps API 설정

지도 기능을 사용하려면 **Google Maps JavaScript API 키**가 필요합니다.

### API 키 생성 방법

1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 새 프로젝트 생성
3. "Maps JavaScript API" 검색 및 활성화
4. 좌측 "사용자 인증 정보" → "+ 사용자 인증 정보 만들기" → "API 키"
5. API 키 복사

### HTML에 적용

`글로벌_채널맵.html` 파일의 247번째 줄 근처:

```html
<script async defer src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY"></script>
```

`YOUR_API_KEY`를 생성한 API 키로 교체

## 🐛 문제 해결

### 지도가 표시되지 않음
- ✅ Google Maps API 키 설정 확인
- ✅ 브라우저 새로고침 (Ctrl+Shift+R)

### 필터가 작동하지 않음
- ✅ CSV 파일이 로드되었는지 확인 (토스트 메시지)
- ✅ 브라우저 콘솔 (F12) 오류 메시지 확인

### 데이터가 로드되지 않음
- ✅ CSV 파일 인코딩이 UTF-8인지 확인
- ✅ 파일이 손상되지 않았는지 확인
